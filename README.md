# Password Based Door Lock System with RFID

A smart security system that combines password authentication
with RFID verification to provide controlled access to a door.

## Features

- RFID card authentication
- Password-based authentication
- Keypad input
- LCD display
- Electronic door lock control

## Technologies

- ESP32
- C++
- RFID
- Keypad
- LCD
- Relay

## Hardware Components

- ESP32
- RFID Module
- RFID Card
- 4x3 Keypad
- 16x2 I2C LCD
- Relay Module
- Electronic Door Lock

## How It Works

The user can authenticate using an RFID card or password.
After successful authentication, the system activates the
door lock mechanism.
